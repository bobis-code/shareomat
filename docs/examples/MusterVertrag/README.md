# LEG-Mustervertrag (Quelle)

Der Vertragstext von Shareomat (`shareomat/web/templates/contract/legal_text.html`) und die
Beitrittserklärung (`contract/beitrittserklaerung.html`) beruhen auf dem
**«Gesellschaftsvertrag LEG Muster»** von [lokalerstrom.ch](https://www.lokalerstrom.ch)
(Word-Vorlage, Stand Dezember 2025).

Die Originaldatei liegt bewusst **nicht** in diesem öffentlichen Repository:
* Sie trägt den Copyright-Vermerk von lokalerstrom.ch.
* lokalerstrom.ch stellt sie selbst zur Verfügung.

Wer den Vergleich braucht, lädt die aktuelle Fassung dort herunter. Bis 17.11.2026 lag
hier eine Kopie; sie ist in der Git-Historie noch enthalten.

Die bewussten Abweichungen vom Muster stehen im Kopfkommentar von `legal_text.html`.
Der Ausdruck lehnt sich gestalterisch an den Aufbau des Musters an (A4, serifenlose
Schrift, Formular mit Linien), ohne dessen Logo oder Farben.
