# EBL-Teilnahmeformular (Quelle)

Die Seite «Dokumente → EBL-Meldungen» druckt die Angaben des Formulars
**«Teilnahmeformular neue LEG-Teilnehmende»** von EBL (Genossenschaft Elektra
Baselland): «Bestätigung Eintritt in LEG durch neuen Teilnehmenden».

Die Originaldatei liegt bewusst **nicht** in diesem öffentlichen Repository
(git-ignoriert): Sie trägt Logo und Absender von EBL, und EBL stellt sie selbst
zur Verfügung. Shareomat übernimmt nur die Felder und die Einverständnis-Erklärung
und druckt sie im eigenen, neutralen Layout ohne EBL-Logo.

Needs verification: ob EBL die Meldung in diesem Layout annimmt. Sonst die Werte
aus Shareomat ins Originalformular übertragen.

Felder und Herkunft in Shareomat: `shareomat/database/participant_documents.py`.
